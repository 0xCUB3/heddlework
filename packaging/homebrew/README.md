# Homebrew cask

`heddlework.rb.tmpl` is rendered by `scripts/release-packages.sh` with the release version and the sha256 of each macOS zip, then pushed to [0xCUB3/homebrew-heddlework](https://github.com/0xCUB3/homebrew-heddlework) on stable releases. Install with `brew install --cask 0xCUB3/heddlework/heddlework`.
